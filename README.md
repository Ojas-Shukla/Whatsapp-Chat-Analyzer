# WhatsApp Chat Analyzer

An interactive data analytics application that transforms raw WhatsApp chat exports into meaningful insights and visualizations. Built using **Python**, **Streamlit**, **Pandas**, and **NLP techniques**, the application enables users to explore chat activity, messaging trends, user participation, and textual patterns through an intuitive web interface.

## Live Demo

🔗 **Deployed Application:** whatsapp-chat-analyzer-w4dqhpsgjj9k7grcqvbny5

## 📌 Features

### Chat Statistics

* Total messages sent
* Total words exchanged
* Media messages shared
* Links shared in chat
* Individual and group-level analytics

### User Analysis

* Most active participants
* Message contribution percentages
* User activity comparison
* Individual user filtering

### Timeline Analysis

* Daily messaging trends
* Monthly activity timeline
* Weekly activity distribution
* Peak chatting periods

### Activity Heatmaps

* Day-wise activity analysis
* Hour-wise activity visualization

### NLP-Based Insights

* Most frequently used words
* Word cloud generation
* Common phrases analysis
* Stopword filtering

### Emoji Analysis

* Most used emojis
* Emoji frequency distribution
* Emoji usage visualization

### Interactive Dashboard

* User-friendly Streamlit interface
* Dynamic filtering options
* Real-time visualization updates
* Responsive charts and graphs

## How to Use

1. Open WhatsApp.
2. Export a chat without media.
3. Download the `.txt` chat file.
4. Upload the exported file in the application.
5. Explore analytics, trends, and visual insights instantly.
